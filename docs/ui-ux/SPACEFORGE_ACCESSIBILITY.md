# SpaceForge accessibility

Target: WCAG 2.2 AA.

- Keyboard: sidebar, command palette, inspector toggle, dialogs trap focus.
- Focus: visible ring (`ring` token).
- Landmarks: banner, navigation, main, complementary (inspector).
- Breadcrumbs: `nav` + current page.
- Charts and graphs: text equivalent or table alternative in later phases.
- `prefers-reduced-motion`.
- Do not rely on color alone for severity.
