# SpaceForge Incident UX

Canonical route: `/v2/incidents`.

Target layout: timeline | investigation | inspector (CAUSE, PREDICT, blast radius, related events).

Current implementation is a list plus a drawer; Phase H replaces the drawer with a split workspace. Demo incident generation belongs under sample data / admin, not as the empty-state headline.

Severity and status must use semantic color only, not decorative palettes.
