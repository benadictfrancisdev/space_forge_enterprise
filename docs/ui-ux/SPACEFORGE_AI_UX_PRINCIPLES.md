# SpaceForge AI UX principles

AI is contextual, not a full-page chatbot.

- **Ask SpaceForge** is global (command palette) and knows the current route.
- Inspector holds explanations for the selected dataset, incident, decision, or entity.
- Marketing `SpaceBotWidget` stays off `/v2`.
- Do not duplicate Data Chat, AI Scientist, and Forecast chatbot as three product identities. They remain **capabilities** on a dataset until those pages are merged.
- Never fill empty states with generated fake metrics.
- Label verified vs unverified model output when the API provides that signal (`Verified AI` only when the bundle says so).
